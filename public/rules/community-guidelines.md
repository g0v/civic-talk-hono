# Civic Talk 社群守則

- **版本**：`2026-08-17`
- **語言**：繁體中文
- **適用平台**：Civic Talk — <https://civic.vtaiwan.tw>
- **相關文件**：[使用條款](https://civic.vtaiwan.tw/terms)、[隱私權政策](https://civic.vtaiwan.tw/privacy)

Civic Talk 是公民審議平台：把散落的新聞、資料與各方說法整理成可討論的議題，讓不同立場的人在同一份事實基礎上表達意見，並說明投稿暫時隱藏時可以怎麼申訴。

本守則與《使用條款》的「行為規範」一節相輔；兩者衝突時，以《使用條款》為準。

---

## 1. 適用範圍

本守則適用於平台上**所有具名投稿**：

| 投稿類型 | API |
| --- | --- |
| 建立議題 | `POST /api/issues` |
| 提交素材 | `POST /api/issues/:id/materials` |
| 發表意見 | `POST /api/issues/:id/opinions` |
| 送出彙整／說明頁 | `POST /api/issues/:id/briefing` |

四種投稿都必須登入，且都會公開附上您提交當下的顯示名稱。**具名是為了可追溯**：每一份內容都有明確的提交者負責。

## 2. 一律禁止的內容

以下六類內容不會被收錄。每一類都標示了對應的濫用分類代碼（見[附錄 A](#附錄-a自動審查分類代碼)）。

### 2.1 濫用與洗版 — `spam`

**屬於違規：**

- 同一內容重複提交，或以多個帳號提交同一內容
- 與議題無關的商業廣告、推銷、招攬、詐騙、投資／博弈／成人網站導流
- 大量無意義字元、亂碼、複製貼上的樣板文字
- 只有連結而沒有任何說明，或連結與議題明顯無關
- 以自動化程式大量產生、未經人工檢視的內容

**不屬於違規：**

- 引用同一份來源支持多個不同議題（只要各篇都有對應該議題的說明）
- 篇幅短但切題的意見——**短不等於洗版**

### 2.2 色情與性內容 — `sexual_content`

**屬於違規：**

- 情色描寫、性行為細節、以性挑逗或滿足性慾為目的的內容
- 未經同意散布的私密影像
- 任何涉及未成年人的性化內容（同時違法，見 2.6）
- 性服務、成人平台的招攬或導流

**不屬於違規：**

- 性別平等、性教育、性工作政策、生殖健康、性暴力防治、同婚等**公共政策討論**
- 以中性語言陳述相關法律、判決、統計或新聞事實
- 性侵害案件的事實敘述——這是公共議題，不是色情內容

### 2.3 人身攻擊與仇恨言論 — `hate_speech`

**屬於違規：**

- 針對特定個人的辱罵、貶抑、羞辱、詛咒，或針對外貌、智識、身分的攻擊
- 針對族群、性別、性傾向、身心障礙、宗教、國籍、原住民族身分、移民身分等的仇恨、歧視或非人化言論
- 騷擾、恐嚇、威脅暴力，或鼓動他人攻擊特定對象
- 未經同意公開他人個資（人肉搜索）：住址、電話、身分證號、工作地點、家人資訊等

**不屬於違規：**

- 對政策、法案、機關或公開人物**作為**的強烈批評——批評行為與主張，不攻擊人格
- 口語粗俗但沒有針對特定對象辱罵
- 引述他人的不當言論作為素材，且標明來源、以檢視為目的（見第 3 節）

### 2.4 誹謗與未經證實的指控 — `defamation`

**屬於違規：**

- 指名特定個人或組織涉及犯罪、貪腐、外遇等具體事實，卻無任何來源或證據
- 把個人猜測寫成既成事實
- 冒用他人身分發言

**不屬於違規：**

- 引述已見報或已進入司法程序的指控，並標明來源
- 明確標示為個人推測、質疑或提問的內容

### 2.5 不實資訊 — `misinformation`

**屬於違規：**

- 明確可被查核為假的事實陳述（偽造引言、篡改數據、假造機關公告）
- 偽造或竄改素材來源、日期、作者
- 把已被撤回或更正的報導當作現況呈現

**不屬於違規：**

- 對同一份數據的不同解讀
- 少數立場、非主流見解——只要事實陳述本身沒有造假
- 已被查核為假、但**明確標示為「待檢視的假訊息案例」**並附上查核結果的素材

### 2.6 違法內容 — `illegal`

**屬於違規：**

- 涉及兒少性剝削的任何內容
- 教唆犯罪、製造武器或毒品的具體指引
- 明知無權轉載仍提交的完整著作內容（授權範圍見《使用條款》「素材授權規範」）
- 其他違反中華民國（台灣）法律的內容

## 3. 不算違規：避免誤判

公民審議必須能討論困難的題目。**以下情形不構成違規**，自動審查與管理員都不得僅因此拒絕內容：

1. **引用式素材**：為了讓大家一起檢視，提交含有攻擊性、不實或爭議內容的原文，並標明來源、以中性語言說明爭點。
2. **針對公共事務的強烈立場**：情緒強烈、用詞直接、明確反對某項政策或某個機關的作為。
3. **敏感題材的政策討論**：死刑、墮胎、性別、移工、毒品、賭博、動物權、戰爭與國防等。
4. **引述法律條文或判決書**，即使其中包含犯罪或性相關的描述。
5. **形式問題**：錯字、中英夾雜、排版混亂、格式不精緻。

兩條判斷原則：

> **攻擊政策可以，攻擊人不行。**
>
> **「引述以供檢視」不等於「散布以助傳播」。**

## 4. 審查與處置

平台提供以下三層機制。**本守則先定義審查標準；實際功能以本節所載上線狀態為準。**

1. **投稿時的自動前置審查（已提供）**
   四種具名投稿在寫入時會讀取本守則並經安全審查。判定違反第 2 節時，該筆投稿仍會成功保存，但會立即標記為暫時隱藏，公開頁面只顯示待管理員複核的佔位訊息；系統同時在 `ct_abuse_reports` 寫入一筆標示 `source=ai`、指向該筆投稿的濫用回報與內容快照，供管理員追溯、複核及申訴處理。審查服務逾時或故障時，系統會放行該次投稿並記錄基礎設施錯誤。

2. **使用者回報（已提供）**
   任何登入者都可以對已收錄的內容提出回報，分類為垃圾訊息、仇恨言論、誹謗、不實資訊、失效連結或其他。回報後該筆內容會被標記待審。

3. **管理員審核（已提供）**
   管理員逐筆處理待審記錄，可以移除內容、標記為誤報（解除標記），或依審核結果停權該帳號。AI 審查造成的暫時隱藏不會自動導致帳號處置。

自動前置審查、違規投稿記錄、平台內建申訴介面、使用者回報與管理員審核均已提供；平台沒有自動停權或自動隱藏門檻。

---

## 5. 申訴誤判

自動審查仍可能出錯。如果您的投稿被標記為暫時隱藏，或帳號已被管理員正式停權，而您認為處置有誤（特別是內容符合第 3 節任一情形）：

1. 請保留您寫好的內容與平台回覆的分類、理由及時間。
2. 屬於引用式素材時，請補上來源連結，並以中性語言說明「為什麼這份素材值得檢視」。
3. 投稿審查回報的內容快照會保留在平台內，請使用平台內建申訴介面附上申訴理由與上述資訊。
4. 管理員會在後台查看申訴並選擇維持（`upheld`）或推翻（`overturned`）原處置；推翻投稿審查結果時，該筆內容會解除暫時隱藏。帳號正式停權則由管理員依複核結果透過帳號系統解除。

如無法使用平台內建介面，仍可透過電子郵件 `info@vtaiwan.tw` 或 [GitHub issue](https://github.com/g0v/civic-talk-hono/issues) 聯絡平台。
